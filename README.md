🐍 Simple Python Calculator

📖 Description

This is a simple calculator program created using Python.

The program allows the user to enter two numbers and choose a mathematical operation. It then calculates and displays the result.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Division-by-zero protection
- ❌ Invalid choice handling
- ⌨️ User input

🛠️ Technologies Used

- Python 3

📚 What I Learned

Through this project, I practiced:

- Using "input()" to receive user information
- Using variables
- Converting input into numbers with "float()"
- Using "if", "elif", and "else"
- Performing mathematical calculations
- Using comparison operators
- Handling division by zero
- Displaying results using "print()"

  
💻 Example

      PYTHON CALCULATOR
